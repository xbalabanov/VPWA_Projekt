# VPWA Chat

Maksym Balabanov, Stanislav Polák · VPWA, FIIT STU

Progresívna webová aplikácia na textovú komunikáciu v štýle IRC/Slack: verejné a súkromné kanály, správy s infinite scrollom, príkazy (`/join`, `/invite`, `/kick`…), `@zmienky`, notifikácie, stav používateľa a „X píše…“.

**Technológie:** Quasar (Vue 3, Options API), Pinia · v 2. fáze AdonisJS a PostgreSQL.

**Stav:** 1. fáza, klikateľný prototyp všetkých 11 prípadov použitia s mock dátami (bez backendu).

## Spustenie

```bash
cd frontend
npm install
npm run dev
```

Testovací účet: `ed@example.com` / `123456`
